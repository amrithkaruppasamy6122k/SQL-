Definition (Vilakkam)

Grant: Database la irukka users ku specific permissions kudukka use panrom. Athavuthu yaaru database access pannalam, yenna operations pannalam nu control panrom.

Revoke: Already kuduttha permissions ah wapas eduthukkalam. User ku access irundha atha remove pannalam.

Flow Chart (Otta Padal)

GRANT PROCESS:
Database Admin → User Select → Permission Type Choose → GRANT Command Execute → User Access Granted
REVOKE PROCESS:
Database Admin → User Select → Permission Type Identify → REVOKE Command Execute → User Access Removed

Basic Syntax (Molip Vagai)

GRANT Syntax:

GRANT permission_type ON database_object TO user_name;

REVOKE Syntax:

REVOKE permission_type ON database_object FROM user_name;

Examples with Explanation (Udaharanangal)

Example 1: SELECT Permission Grant Pannurathu

GRANT SELECT ON students TO ravi;
GRANT: Permission kudukka command
SELECT: Data padicka allow pannurom
ON students: Students table la mattum
TO ravi: Ravi user ku permission kodukurom

Example 2: Multiple Permissions Grant

GRANT SELECT, INSERT, UPDATE ON products TO manager_user;
SELECT, INSERT, UPDATE: Moonru permissions um kodukkurom
ON products: Products table la mattum
TO manager_user: Manager user ku access

Example 3: ALL Privileges Grant

GRANT ALL PRIVILEGES ON company_db.* TO admin_user;
ALL PRIVILEGES: Ellaa permissions um kodukkurom
ON company_db.*: Company database la ella tables layum
TO admin_user: Admin user ku full access

Example 4: SELECT Permission Revoke

REVOKE SELECT ON students FROM ravi;
REVOKE: Permission wapas edukkurom
SELECT: Padicka permission remove pannurom
FROM ravi: Ravi user la irundhu edukkurom

Example 5: Multiple Permissions Revoke

REVOKE INSERT, UPDATE ON products FROM manager_user;
INSERT, UPDATE: Rendu permissions um remove pannurom
FROM manager_user: Manager user la irundhu edukurom

Use Cases (Payan Paadu Nilai)

1. Employee Management System

HR department ku employee data access venum aana salary details venam. Appo specific columns ku mattum permission kodukalam.

2. E-commerce Application

Customer service team ku order details paakka permission venum aana customer payment info access venam.

3. Banking System

Junior staff ku account balance check panna permission venum aana transaction approve panna permission kudukka koodaathu.

4. Educational Portal

Student ku own marks paakka permission venum aana other students marks paakka permission venam.
