Chapter 5: DDL, DML, TCL, DCL Overview

📖 Definition

SQL Command Categories: SQL-la irukura ella commands-um 4 main categories-la divide pannirukura. Each category-ku specific purpose iruku - structure work, data work, transaction control, access control. Inda classification purinjuka SQL mastery-ku romba important.

🎯 Four Main Categories

🏗️ DDL

Data Definition Language

Database structure create/modify panradhu

CREATE ALTER DROP

📊 DML

Data Manipulation Language

Data work panradhu - insert, update, delete

INSERT UPDATE DELETE SELECT

🔄 TCL

Transaction Control Language

Database changes control panradhu

COMMIT ROLLBACK SAVEPOINT

🔐 DCL

Data Control Language

User permissions control panradhu

GRANT REVOKE

💡 DDL (Data Definition Language) Examples

-- Table create panradhu CREATE TABLE students ( id INT PRIMARY KEY, name VARCHAR(50), age INT ); -- Table structure modify panradhu ALTER TABLE students ADD COLUMN email VARCHAR(100); -- Table delete panradhu DROP TABLE students;
Line-by-Line Explanation:
CREATE TABLE students - 'students' naam-oda table create panrom
id INT PRIMARY KEY - Integer type-oda primary key column
name VARCHAR(50) - 50 characters maximum text column
ALTER TABLE... ADD COLUMN - Existing table-la new column add panrom
DROP TABLE - Table-ae completely delete pannurom

💡 DML (Data Manipulation Language) Examples

-- Data insert panradhu INSERT INTO students (id, name, age) VALUES (1, 'Raj', 20); -- Data retrieve panradhu SELECT * FROM students WHERE age > 18; -- Data update panradhu UPDATE students SET age = 21 WHERE id = 1; -- Data delete panradhu DELETE FROM students WHERE age < 18;
Line-by-Line Explanation:
INSERT INTO students - Students table-la new record add panrom
VALUES (1, 'Raj', 20) - Actual data values specify panrom
SELECT * FROM students - Students table-la irukura ella data-yum retrieve panrom
WHERE age > 18 - 18 years-ku mela irukura records mattum filter panrom
UPDATE... SET - Existing data-va modify panrom
DELETE FROM... WHERE - Specific condition-oda records delete panrom

💡 TCL (Transaction Control Language) Examples

-- Transaction start panradhu START TRANSACTION; -- Multiple operations INSERT INTO students VALUES (2, 'Priya', 22); UPDATE students SET age = 23 WHERE name = 'Raj'; -- Changes confirm panradhu COMMIT; -- Or changes cancel panradhu -- ROLLBACK;
Line-by-Line Explanation:
START TRANSACTION - Transaction begin pannurom
Multiple operations - Several changes panrom, but temporary-a irukum
COMMIT - Ella changes-um permanently save pannurom
ROLLBACK - Ella changes-um cancel panni original state-ku porom

💡 DCL (Data Control Language) Examples

-- User-ku permission kudukkura GRANT SELECT, INSERT ON students TO 'user1'@'localhost'; -- User permissions check panradhu SHOW GRANTS FOR 'user1'@'localhost'; -- Permission remove panradhu REVOKE INSERT ON students FROM 'user1'@'localhost';
Line-by-Line Explanation:
GRANT SELECT, INSERT - User1-ku data read panna um, insert panna um permission kudukom
ON students TO 'user1' - Students table-ku mattum access kudukom
SHOW GRANTS - User-ku enna permissions iruku-nu paapom
REVOKE INSERT - Insert permission-a remove panrom

🔧 Use Cases

1. E-commerce Application Development

DDL: Products, users, orders tables create panradhu
DML: Product details add panradhu, orders update panradhu
TCL: Payment processing-la transaction control
DCL: Different users-ku different access levels

2. Banking System

DDL: Accounts, transactions, customer tables
DML: Money transfer, balance update
TCL: Fund transfer-la ACID properties maintain panradhu
DCL: Teller, manager, admin-ku different permissions

3. Hospital Management System

DDL: Patients, doctors, appointments table structure
DML: Patient records maintain panradhu
TCL: Critical updates-la data consistency ensure panradhu
DCL: Doctor, nurse, admin-ku role-based access

📝 Key Points to Remember

  • DDL: Structure work - auto-commit aagum
  • DML: Data work - rollback possible
  • TCL: Transaction safety-ku use panrom
  • DCL: Security-ku important
  • Proper sequence: DDL → DML → TCL → DCL
