💡 Basic Notebook Example

Show Available Databases SHOW DATABASES; -- 3. Create Practice Database CREATE DATABASE IF NOT EXISTS practice_db; -- 4. Use Practice Database USE practice_db; -- 5. Show Current Database SELECT DATABASE() AS current_database;
✓
Query Explanations:
VERSION() - MySQL version number return pannum
SHOW DATABASES - Available databases list pannurum
CREATE DATABASE - New database create pannum

DATABASE() - Current active database name return pannum
