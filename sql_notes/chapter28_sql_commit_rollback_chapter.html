📖 Definition (Transactions Enna da Machan?)

Transaction na database la execute agura related operations oda collection thaan, adhu ellam successful aana commit pannum, yaarachu error vanthu failure aana ellam operations ah rollback panni original state ku return pannum. Idhu database integrity maintain panradhu ku romba mukkiyam!

Transaction Management oda powerful capabilities:

  • Data Consistency: All-or-nothing approach - ellam success yaa ellam failure
  • Error Recovery: Error aana original state ku automatic ah return aagidum
  • Concurrent Access: Multiple users access pannumpothu data corruption prevent pannum
  • Business Logic: Complex business operations ah safely execute panalam
  • Audit Trail: Every transaction details track panna mudiyum
  • Performance: Batch operations efficient ah handle panalam

🔄 Transaction Lifecycle:

  • BEGIN/START TRANSACTION: Transaction start panrom
  • EXECUTE: Database operations perform panrom
  • COMMIT: All changes permanently save panrom
  • ROLLBACK: All changes undo panni original state restore panrom

💎 ACID Properties (Transaction oda Foundation):

  • Atomicity: Transaction complete ah success aaganum yaa complete ah fail aaganum
  • Consistency: Database always valid state la irukanum
  • Isolation: Concurrent transactions interfere pannakoodadhu
  • Durability: Committed data permanent ah store aaganum

⚠️ Transaction la Careful Ah Irukkanum:

  • Deadlock Issues: Multiple transactions wait pannina system hang aagum
  • Long Transactions: Too long transactions performance affect pannum
  • Nested Transactions: Complex nested structures avoid pannunga
  • Auto-commit: Default auto-commit mode enable/disable properly handle pananum
  • Connection Management: Transaction connection close aana automatic rollback aagum

🏛️ Standard (Transaction Control Statements)

MySQL la different transaction control commands irukku, each one specific purpose ku optimized:

Command Tamil la Explanation Usage Impact
START TRANSACTION Transaction ah start panradhu ku BEGIN; or START TRANSACTION; Auto-commit disable aagum
COMMIT Changes ah permanently save panradhu ku COMMIT; All pending changes finalized
ROLLBACK Changes ah undo panni original state restore panradhu ku ROLLBACK; All changes since BEGIN discarded
SAVEPOINT Transaction kulla checkpoint create panradhu ku SAVEPOINT name; Partial rollback possible
ROLLBACK TO Specific savepoint ku rollback panradhu ku ROLLBACK TO name; Partial transaction undo
SET AUTOCOMMIT Auto-commit mode control panradhu ku SET AUTOCOMMIT = 0/1; Transaction behavior change

📍 Transaction Types:

  • Implicit Transactions: Single statement transactions (auto-commit enabled)
  • Explicit Transactions: Manual START/COMMIT/ROLLBACK controlled
  • Read-only Transactions: Only SELECT operations allowed
  • Read-write Transactions: All DML operations allowed
  • Distributed Transactions: Multiple databases across transactions

💡 Transaction Best Practices:

  • Keep it Short: Long transactions avoid pannunga, performance issues varum
  • Error Handling: Proper try-catch blocks use panni rollback implement pannunga
  • Savepoints: Complex transactions la intermediate savepoints use pannunga
  • Lock Management: Unnecessary table locks avoid pannunga
  • Connection Pool: Database connections properly manage pannunga

END$ DELIMITER ; -- Procedure call pannalam CALL ProcessMonthlySalary(12, 2024);

-- Comprehensive banking fund transfer system DELIMITER $ CREATE PROCEDURE BankFundTransfer( IN p_from_account VARCHAR(20), IN p_to_account VARCHAR(20), IN p_amount DECIMAL(12,2), IN p_transfer_type VARCHAR(20), IN p_description VARCHAR(200), OUT p_transaction_id VARCHAR(50), OUT p_status VARCHAR(100) ) BEGIN DECLARE v_from_balance DECIMAL(12,2) DEFAULT 0; DECLARE v_from_bank_code VARCHAR(10); DECLARE v_to_bank_code VARCHAR(10); DECLARE v_transfer_fee DECIMAL(8,2) DEFAULT 0; DECLARE v_daily_limit DECIMAL(12,2) DEFAULT 0; DECLARE v_today_transferred DECIMAL(12,2) DEFAULT 0; DECLARE v_min_balance DECIMAL(10,2) DEFAULT 1000; DECLARE EXIT HANDLER FOR SQLEXCEPTION BEGIN ROLLBACK; SET p_status = 'FAILED: Transaction rolled back due to error'; SET p_transaction_id = NULL; END; START TRANSACTION; -- From account validation and balance check SELECT a.current_balance, a.bank_code, c.daily_transfer_limit INTO v_from_balance, v_from_bank_code, v_daily_limit FROM accounts a JOIN customers c ON a.customer_id = c.customer_id WHERE a.account_number = p_from_account AND a.status = 'ACTIVE' AND a.account_type != 'FROZEN' FOR UPDATE; -- To account validation SELECT bank_code INTO v_to_bank_code FROM accounts WHERE account_number = p_to_account AND status = 'ACTIVE'; -- Transfer fee calculation SET v_transfer_fee = CASE WHEN v_from_bank_code = v_to_bank_code THEN 0 -- Same bank WHEN p_amount <= 10000 THEN 5 -- Inter-bank small amount ELSE 25 -- Inter-bank large amount END; -- Daily limit check SELECT COALESCE(SUM(amount + transfer_fee), 0) INTO v_today_transferred FROM fund_transfers WHERE from_account = p_from_account AND transfer_date = CURDATE() AND status = 'COMPLETED'; -- Validation checks IF v_from_balance IS NULL THEN ROLLBACK; SET p_status = 'FAILED: From account not found or inactive'; SET p_transaction_id = NULL; ELSEIF v_to_bank_code IS NULL THEN ROLLBACK; SET p_status = 'FAILED: To account not found or inactive'; SET p_transaction_id = NULL; ELSEIF (v_from_balance - p_amount - v_transfer_fee) < v_min_balance THEN ROLLBACK; SET p_status = CONCAT('FAILED: Insufficient balance. Available: ₹', v_from_balance - v_min_balance); SET p_transaction_id = NULL; ELSEIF (v_today_transferred + p_amount + v_transfer_fee) > v_daily_limit THEN ROLLBACK; SET p_status = CONCAT('FAILED: Daily limit exceeded. Remaining: ₹', v_daily_limit - v_today_transferred); SET p_transaction_id = NULL; ELSE -- Generate unique transaction ID SET p_transaction_id = CONCAT( 'TXN', DATE_FORMAT(NOW(), '%Y%m%d'), LPAD(CONNECTION_ID(), 6, '0'), LPAD(UNIX_TIMESTAMP(NOW()) % 1000000, 6, '0') ); -- Debit from sender account UPDATE accounts SET current_balance = current_balance - p_amount - v_transfer_fee, last_transaction_date = NOW() WHERE account_number = p_from_account; -- Credit to receiver account UPDATE accounts SET current_balance = current_balance + p_amount, last_transaction_date = NOW() WHERE account_number = p_to_account; -- Fund transfer record INSERT INTO fund_transfers ( transaction_id, from_account, to_account, amount, transfer_fee, transfer_type, transfer_date, description, status ) VALUES ( p_transaction_id, p_from_account, p_to_account, p_amount, v_transfer_fee, p_transfer_type, NOW(), p_description, 'COMPLETED' ); -- Transaction history for both accounts INSERT INTO account_transactions ( account_number, transaction_id, transaction_type, amount, balance_after, transaction_date, description ) VALUES ( p_from_account, p_transaction_id, 'DEBIT', -(p_amount + v_transfer_fee), v_from_balance - p_amount - v_transfer_fee, NOW(), CONCAT('Fund transfer to ', p_to_account, ': ', p_description) ), ( p_to_account, p_transaction_id, 'CREDIT', p_amount, (SELECT current_balance FROM accounts WHERE account_number = p_to_account), NOW(), CONCAT('Fund transfer from ', p_from_account, ': ', p_description) ); -- Notification records INSERT INTO notifications ( account_number, notification_type, message, created_date, status ) VALUES ( p_from_account, 'DEBIT_ALERT', CONCAT('₹', p_amount, ' debited. Txn ID: ', p_transaction_id), NOW(), 'PENDING' ), ( p_to_account, 'CREDIT_ALERT', CONCAT('₹', p_amount, ' credited. Txn ID: ', p_transaction_id), NOW(), 'PENDING' ); COMMIT; SET p_status = CONCAT('SUCCESS: ₹', p_amount, ' transferred successfully. Fee: ₹', v_transfer_fee); END IF; END$ DELIMITER ; -- Fund transfer example CALL BankFundTransfer('ACC001', 'ACC002', 15000, 'IMPS', 'Salary transfer', @txn_id, @status); SELECT @txn_id AS TransactionID, @status AS TransferStatus;

-- Hospital patient treatment processing DELIMITER $ CREATE PROCEDURE ProcessPatientTreatment( IN p_patient_id INT, IN p_doctor_id INT, IN p_treatment_type VARCHAR(50), IN p_medications JSON, IN p_insurance_claim BOOLEAN, OUT p_treatment_id INT, OUT p_total_cost DECIMAL(10,2), OUT p_result VARCHAR(200) ) BEGIN DECLARE v_consultation_fee DECIMAL(8,2) DEFAULT 0; DECLARE v_medication_cost DECIMAL(10,2) DEFAULT 0; DECLARE v_insurance_coverage DECIMAL(5,2) DEFAULT 0; DECLARE v_patient_balance DECIMAL(10,2) DEFAULT 0; DECLARE v_med_count INT DEFAULT 0; DECLARE v_med_id INT; DECLARE v_med_quantity INT; DECLARE v_med_unit_cost DECIMAL(8,2); DECLARE v_available_stock INT; DECLARE i INT DEFAULT 0; DECLARE EXIT HANDLER FOR SQLEXCEPTION BEGIN ROLLBACK; SET p_result = 'ERROR: Treatment processing failed, all changes rolled back'; SET p_treatment_id = 0; SET p_total_cost = 0; END; START TRANSACTION; -- Doctor consultation fee get panrom SELECT consultation_fee INTO v_consultation_fee FROM doctors WHERE doctor_id = p_doctor_id AND status = 'ACTIVE'; -- Patient insurance coverage check panrom IF p_insurance_claim THEN SELECT COALESCE(coverage_percentage, 0), available_balance INTO v_insurance_coverage, v_patient_balance FROM patient_insurance WHERE patient_id = p_patient_id AND policy_status = 'ACTIVE' AND expiry_date > CURDATE(); END IF; -- Medication cost calculation and stock validation SET v_med_count = JSON_LENGTH(p_medications); medication_loop: WHILE i < v_med_count DO SET v_med_id = JSON_UNQUOTE(JSON_EXTRACT(p_medications, CONCAT('$[', i, '].medication_id'))); SET v_med_quantity = JSON_UNQUOTE(JSON_EXTRACT(p_medications, CONCAT('$[', i, '].quantity'))); -- Medication stock and price check SELECT unit_cost, available_stock INTO v_med_unit_cost, v_available_stock FROM pharmacy_inventory WHERE medication_id = v_med_id; -- Stock validation IF v_available_stock < v_med_quantity THEN ROLLBACK; SET p_result = CONCAT('ERROR: Insufficient stock for medication ID ', v_med_id); SET p_treatment_id = 0; LEAVE medication_loop; END IF; SET v_medication_cost = v_medication_cost + (v_med_unit_cost * v_med_quantity); SET i = i + 1; END WHILE; -- Total cost calculation SET p_total_cost = v_consultation_fee + v_medication_cost; -- Insurance deduction IF p_insurance_claim AND v_insurance_coverage > 0 THEN SET p_total_cost = p_total_cost * (1 - v_insurance_coverage/100); END IF; -- Treatment record create panrom INSERT INTO patient_treatments ( patient_id, doctor_id, treatment_date, treatment_type, consultation_fee, medication_cost, total_cost, insurance_claimed, insurance_coverage, status ) VALUES ( p_patient_id, p_doctor_id, NOW(), p_treatment_type, v_consultation_fee, v_medication_cost, p_total_cost, p_insurance_claim, v_insurance_coverage, 'COMPLETED' ); SET p_treatment_id = LAST_INSERT_ID(); -- Medication prescription records SET i = 0; WHILE i < v_med_count DO SET v_med_id = JSON_UNQUOTE(JSON_EXTRACT(p_medications, CONCAT('$[', i, '].medication_id'))); SET v_med_quantity = JSON_UNQUOTE(JSON_EXTRACT(p_medications, CONCAT('$[', i, '].quantity'))); -- Prescription record INSERT INTO prescriptions ( treatment_id, patient_id, medication_id, quantity, dosage_instructions, prescribed_date ) VALUES ( p_treatment_id, p_patient_id, v_med_id, v_med_quantity, 'As directed by doctor', NOW() ); -- Pharmacy inventory update UPDATE pharmacy_inventory SET available_stock = available_stock - v_med_quantity, last_updated = NOW() WHERE medication_id = v_med_id; SET i = i + 1; END WHILE; -- Patient billing record INSERT INTO patient_bills ( patient_id, treatment_id, bill_date, consultation_charges, medication_charges, total_amount, insurance_covered, patient_payable, payment_status ) VALUES ( p_patient_id, p_treatment_id, NOW(), v_consultation_fee, v_medication_cost, v_consultation_fee + v_medication_cost, (v_consultation_fee + v_medication_cost) - p_total_cost, p_total_cost, 'PENDING' ); -- Insurance claim record IF p_insurance_claim AND v_insurance_coverage > 0 THEN INSERT INTO insurance_claims ( patient_id, treatment_id, claim_date, claim_amount, coverage_percentage, claim_status ) VALUES ( p_patient_id, p_treatment_id, NOW(), (v_consultation_fee + v_medication_cost) - p_total_cost, v_insurance_coverage, 'SUBMITTED' ); END IF; COMMIT; SET p_result = CONCAT('SUCCESS: Treatment processed. Patient payable: ₹', p_total_cost); END$ DELIMITER ; -- Treatment processing example SET @medications = '[{"medication_id": 101, "quantity": 10}, {"medication_id": 102, "quantity": 5}]'; CALL ProcessPatientTreatment(1001, 501, 'General Consultation', @medications, TRUE, @treatment_id, @cost, @result); SELECT @treatment_id AS TreatmentID, @cost AS TotalCost, @result AS ProcessingResult;
