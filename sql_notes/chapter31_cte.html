Definition (Vilakkam)

Common Table Expression (CTE): Temporary named result set ah create pannuradhu, itha single query la use pannalam. WITH keyword use panni define pannurom. Complex queries ah readable and maintainable ah make panna CTE romba useful.

Advantages: Code readability increase aagum, complex subqueries ah simple ah write pannalam, same CTE ah multiple times reference pannalam, recursive operations perform pannalam.

Flow Chart (Otta Padal)

SIMPLE CTE PROCESS:
WITH keyword → CTE name define → AS keyword → Subquery write → Main query la CTE use pannu
RECURSIVE CTE PROCESS:
WITH RECURSIVE → Base case define → UNION ALL → Recursive case define → Main query execute
MULTIPLE CTE PROCESS:
First CTE define → Comma → Second CTE define → Multiple CTEs reference → Main query execute

Types of CTE (Vakai Vakai)

1. Simple CTE (Eliya CTE)

Basic temporary result set create pannuradhu

2. Recursive CTE (Punar CTE)

Self-referencing query, hierarchy data handle pannuradhu

3. Multiple CTE (Pala CTE)

Orey query la multiple CTEs use pannuradhu

Basic Syntax (Molip Vagai)

WITH cte_name AS ( -- CTE query SELECT column1, column2 FROM table_name WHERE condition ) SELECT * FROM cte_name WHERE another_condition;
WITH cte_name AS: CTE name define pannurom
SELECT ... FROM table_name: Temporary result set create pannurom
SELECT * FROM cte_name: CTE results ah main query la use pannurom

Examples with Explanation (Udaharanangal)

Example 1: Basic CTE - Department wise Employee Count

WITH dept_summary AS ( SELECT department, COUNT(*) as emp_count FROM employees GROUP BY department ) SELECT * FROM dept_summary WHERE emp_count > 5;
WITH dept_summary AS: dept_summary name la CTE create pannurom
SELECT department, COUNT(*): Department wise employee count calculate pannurom
FROM employees: Employees table la irundhu data edukkurom
GROUP BY department: Department wise group pannurom
SELECT * FROM dept_summary: CTE results ah use pannurom
WHERE emp_count > 5: 5 ku mela employees irukka departments mattum filter pannurom

Example 2: CTE with JOIN Operations

WITH high_salary_emp AS ( SELECT emp_id, emp_name, salary FROM employees WHERE salary > 50000 ) SELECT h.emp_name, h.salary, d.dept_name FROM high_salary_emp h JOIN departments d ON h.emp_id = d.manager_id;
WITH high_salary_emp AS: High salary employees ah separate pannurom
WHERE salary > 50000: 50000 ku mela salary irukkavanga mattum
SELECT h.emp_name, h.salary: CTE la irundhu employee details edukkurom
JOIN departments d: Departments table ah join pannurom
ON h.emp_id = d.manager_id: Employee ID and Manager ID match pannurom

Example 3: Multiple CTEs

WITH sales_summary AS ( SELECT product_id, SUM(quantity) as total_sold FROM sales GROUP BY product_id ), product_details AS ( SELECT product_id, product_name, price FROM products ) SELECT p.product_name, p.price, s.total_sold, (p.price * s.total_sold) as total_revenue FROM product_details p JOIN sales_summary s ON p.product_id = s.product_id;
WITH sales_summary AS: First CTE - sales summary create pannurom
SUM(quantity) as total_sold: Product wise total quantity sum pannurom
product_details AS: Second CTE - product details ah separate pannurom
SELECT product_id, product_name: Product information edukkurom
JOIN sales_summary s: Rendu CTEs ah join pannurom
(p.price * s.total_sold): Total revenue calculate pannurom

Example 4: Recursive CTE - Employee Hierarchy

WITH RECURSIVE emp_hierarchy AS ( SELECT emp_id, emp_name, manager_id, 1 as level FROM employees WHERE manager_id IS NULL UNION ALL SELECT e.emp_id, e.emp_name, e.manager_id, h.level + 1 FROM employees e JOIN emp_hierarchy h ON e.manager_id = h.emp_id ) SELECT emp_name, level FROM emp_hierarchy ORDER BY level, emp_name;
WITH RECURSIVE emp_hierarchy: Recursive CTE define pannurom
WHERE manager_id IS NULL: Top level managers ah base case ah edukkurom
1 as level: First level ah 1 ah set pannurom
UNION ALL: Base case and recursive case ah combine pannurom
JOIN emp_hierarchy h: CTE ah self-reference pannurom
h.level + 1: Next level employees ku level increment pannurom
ORDER BY level, emp_name: Level wise sort pannurom

Example 5: CTE with Window Functions

WITH ranked_employees AS ( SELECT emp_name, department, salary, ROW_NUMBER() OVER(PARTITION BY department ORDER BY salary DESC) as rank_num FROM employees ) SELECT emp_name, department, salary FROM ranked_employees WHERE rank_num <= 3;
WITH ranked_employees AS: Employee ranking CTE create pannurom
ROW_NUMBER() OVER: Window function use panni ranking pannurom
PARTITION BY department: Department wise separate panni rank pannurom
ORDER BY salary DESC: Salary high to low order la arrange pannurom
WHERE rank_num <= 3: Top 3 employees ah mattum select pannurom

Advantages (Nanmaigal)

1. Code Readability (Puridhal)

Complex queries ah simple steps la break down pannalam

2. Reusability (Marupadiyum Payan)

Same CTE ah multiple places la reference pannalam

3. Performance (Seyalthiran)

Subquery alternative ah use panninaala performance better aagum

4. Recursive Operations

Hierarchy data, tree structures handle panna easy

Use Cases (Payan Paadu Nilai)

1. Sales Report Generation

Monthly sales summary, product wise performance, region wise analysis ellaam CTE use panni clear ah generate pannalam.

2. Employee Management

Department hierarchy, reporting structure, performance ranking ellaam recursive CTE use panni handle pannalam.

3. E-commerce Analytics

Customer segmentation, product recommendations, order analysis ellaam multiple CTEs use panni complex analysis pannalam.

4. Financial Reporting

Quarter wise revenue, expense analysis, profit calculation ellaam step by step CTE la break down panni clear report create pannalam.

Definition (Vilakkam)

Database Normalization: Database design la redundancy (duplicate data) reduce pannuradhu and data integrity maintain pannuradhu. Itha different normal forms la organize pannurom (1NF, 2NF, 3NF, BCNF).

First Normal Form (1NF) Example:

-- Before 1NF (Atomic values illai) CREATE TABLE students_bad ( id INT, name VARCHAR(100), subjects VARCHAR(200) -- "Math, Science, English" ); -- After 1NF (Atomic values) CREATE TABLE students_good ( id INT, name VARCHAR(100), subject VARCHAR(50) );
Before 1NF: Single column la multiple values store pannurom (wrong)
After 1NF: Each column la single atomic value mattum store pannurom
Atomic values: Each cell la oru value mattum irukanum
