Definition (Vilakkam)

Python Database Connectivity: Python program la irundhu MySQL database ku connect panni data operations pannurathu. Ithukullu mysql-connector-python library use pannurom. Itha JDBC (Java Database Connectivity) concept Python la implement pannalam.

MySQL Connector: Python and MySQL database ku naduvula bridge pola work pannum. Query execute pannalam, data retrieve pannalam, insert/update/delete operations lam pannalam.

Flow Chart (Otta Padal)

DATABASE CONNECTION PROCESS:
Install mysql-connector → Import Library → Create Connection → Create Cursor → Execute Query → Fetch Results → Close Connection
ERROR HANDLING FLOW:
Try Block → Database Operation → Success/Exception → Handle Error → Finally Close Connection

Examples with Explanation (Udaharanangal)

Example 1: Basic Database Connection

import mysql.connector
import mysql.connector: MySQL connection library ah import pannurom
connection = mysql.connector.connect( host='localhost', database='school_db', user='root', password='admin123' )
mysql.connector.connect(): Database ku connection establish pannurom
host='localhost': Database server address (local machine la irukku)
database='school_db': Connect panna database name
user='root': Database username
password='admin123': Database login password

Example 2: Create Table

cursor = connection.cursor()
cursor(): SQL commands execute panna cursor object create pannurom
create_table_query = """ CREATE TABLE students ( id INT AUTO_INCREMENT PRIMARY KEY, name VARCHAR(100), age INT, grade VARCHAR(10) ) """
CREATE TABLE: Students table create pannurom
id INT AUTO_INCREMENT: Primary key auto increment pannurom
name VARCHAR(100): Student name 100 characters varaikum
age INT: Age number format la
grade VARCHAR(10): Grade string format la
cursor.execute(create_table_query)
cursor.execute(): SQL query ah execute pannurom

Example 3: Insert Data

insert_query = "INSERT INTO students (name, age, grade) VALUES (%s, %s, %s)"
INSERT INTO: Students table la data insert pannurom
VALUES (%s, %s, %s): Placeholder values, python variables bind pannurom
student_data = ("Ravi Kumar", 18, "12th")
student_data: Insert panna data ah tuple format la store pannurom
cursor.execute(insert_query, student_data)
cursor.execute(query, data): Query and data rendumaayum pass pannurom
connection.commit()
connection.commit(): Changes ah database la permanently save pannurom

Example 4: Select Data

select_query = "SELECT * FROM students WHERE age > %s"
SELECT * FROM students: Students table la irukka ellaa data vayum select pannurom
WHERE age > %s: Age condition based la filter pannurom
cursor.execute(select_query, (16,))
(16,): Age 16 ku mela irukkavangala mattum select pannurom
results = cursor.fetchall()
cursor.fetchall(): Query results ellathayum fetch panni variable la store pannurom
for row in results: print(f"ID: {row[0]}, Name: {row[1]}, Age: {row[2]}, Grade: {row[3]}")
for row in results: Ellaa rows layum loop pannurom
print(f"..."): Each row data ah formatted ah print pannurom
row[0], row[1]: Column index based la data access pannurom

Example 5: Error Handling and Connection Close

try: connection = mysql.connector.connect( host='localhost', database='school_db', user='root', password='admin123' ) cursor = connection.cursor() query = "SELECT * FROM students" cursor.execute(query) results = cursor.fetchall() for row in results: print(row) except mysql.connector.Error as error: print(f"Database error: {error}") finally: if connection.is_connected(): cursor.close() connection.close() print("Connection closed successfully")
try: Database operations ah try block la pannurom
except mysql.connector.Error: MySQL specific errors ah catch pannurom
finally: Error irundhaalum illanaalum connection close pannurom
connection.is_connected(): Connection active ah irukkanu check pannurom
cursor.close(): Cursor ah close pannurom
connection.close(): Database connection ah close pannurom

Next Chapter Sample: Common Table Expressions (CTE)

Definition (Vilakkam)

Common Table Expression (CTE): Temporary result set ah define pannuradhu, itha main query la use pannalam. WITH keyword use panni create pannurom. Complex queries ah simple ah readable ah write panna CTE use pannurom.

Basic CTE Example:

WITH student_avg AS ( SELECT grade, AVG(marks) as avg_marks FROM students GROUP BY grade ) SELECT * FROM student_avg WHERE avg_marks > 75;
WITH student_avg AS: student_avg name la CTE create pannurom
SELECT grade, AVG(marks): Grade wise average marks calculate pannurom
FROM students GROUP BY grade: Students table la grade wise group pannurom
SELECT * FROM student_avg: CTE result ah use panni final query run pannurom
