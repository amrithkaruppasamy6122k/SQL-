📝 Understanding NULL Behavior

NULL Key Properties:

• NULL is not equal to anything - NULL = NULL returns NULL (not TRUE)
• NULL in arithmetic operations - Any calculation with NULL results in NULL
• NULL in string operations - Concatenation with NULL results in NULL
• NULL in comparisons - Always use IS NULL / IS NOT NULL
• NULL in aggregations - Aggregation functions ignore NULL values

❓ IS NULL and IS NOT NULL

-- Basic NULL checking examples -- Find customers with no primary phone SELECT customer_name, primary_phone, email_address FROM customer_contacts WHERE primary_phone IS NULL; -- Find customers with contact information SELECT customer_name, primary_phone, email_address FROM customer_contacts WHERE primary_phone IS NOT NULL AND email_address IS NOT NULL; -- Find customers with missing emergency contact SELECT customer_name, primary_phone, emergency_contact_name, emergency_contact_phone FROM customer_contacts WHERE emergency_contact_name IS NULL OR emergency_contact_phone IS NULL; -- Count NULL values in different columns SELECT COUNT(*) AS total_customers, COUNT(primary_phone) AS customers_with_primary_phone, COUNT(secondary_phone) AS customers_with_secondary_phone, COUNT(email_address) AS customers_with_email, COUNT(home_address) AS customers_with_home_address, -- Calculate percentage of NULL values ROUND((COUNT(*) - COUNT(primary_phone)) * 100.0 / COUNT(*), 2) AS primary_phone_null_percentage, ROUND((COUNT(*) - COUNT(email_address)) * 100.0 / COUNT(*), 2) AS email_null_percentage FROM customer_contacts;

🔧 IFNULL Function (MySQL Specific)

-- IFNULL examples - MySQL specific NULL handling -- Replace NULL phone numbers with default message SELECT customer_name, primary_phone, IFNULL(primary_phone, 'Phone Not Provided') AS phone_display, secondary_phone, IFNULL(secondary_phone, 'Secondary Phone Not Available') AS secondary_display FROM customer_contacts; -- Replace NULL addresses with meaningful defaults SELECT customer_name, IFNULL(home_address, 'Home Address Not Available') AS home_address_display, IFNULL(office_address, 'Office Address Not Available') AS office_address_display, -- Combine with calculations IFNULL(home_address, office_address) AS any_available_address, -- Use with string functions IFNULL(UPPER(emergency_contact_name), 'NO EMERGENCY CONTACT') AS emergency_name_upper FROM customer_contacts; -- IFNULL with aggregation and calculations SELECT customer_name, registration_date, IFNULL(notes, 'Standard Customer') AS customer_category, -- Calculate days since registration (handle NULL dates) IFNULL( DATEDIFF(CURDATE(), registration_date), 0 ) AS days_since_registration, -- Convert NULL to zero for calculations IFNULL(LENGTH(notes), 0) AS notes_character_count FROM customer_contacts ORDER BY registration_date DESC;

🚫 NULLIF Function

-- NULLIF examples - return NULL when values are equal -- Convert empty strings to NULL SELECT customer_name, primary_phone, NULLIF(primary_phone, '') AS cleaned_primary_phone, email_address, NULLIF(email_address, '') AS cleaned_email, -- Convert placeholder values to NULL NULLIF(notes, 'N/A') AS meaningful_notes, NULLIF(notes, 'TBD') AS non_placeholder_notes FROM customer_contacts; -- Prevent division by zero errors SELECT customer_name, LENGTH(COALESCE(notes, '')) AS notes_length, LENGTH(COALESCE(home_address, '')) AS address_length, -- Safe division using NULLIF CASE WHEN NULLIF(LENGTH(COALESCE(notes, '')), 0) IS NOT NULL THEN ROUND(LENGTH(COALESCE(home_address, '')) / LENGTH(COALESCE(notes, '')), 2) ELSE NULL END AS address_to_notes_ratio, -- Another approach with NULLIF ROUND( LENGTH(COALESCE(home_address, '')) / NULLIF(LENGTH(COALESCE(notes, '')), 0), 2 ) AS safe_ratio FROM customer_contacts WHERE notes IS NOT NULL OR home_address IS NOT NULL; -- Data cleansing with NULLIF SELECT customer_name, -- Convert various "empty" representations to actual NULL NULLIF(TRIM(primary_phone), '') AS cleaned_phone, NULLIF(TRIM(LOWER(email_address)), 'unknown') AS cleaned_email, NULLIF(TRIM(notes), 'No notes') AS cleaned_notes, NULLIF(TRIM(emergency_contact_name), 'None') AS cleaned_emergency_contact FROM customer_contacts;
NULLIF Function Explanation:
NULLIF(expr1, expr2) - Expr1 and expr2 equal-na NULL return pannum, illa-na expr1 return pannum

📊 NULL Handling in Aggregations

-- NULL behavior in aggregation functions -- Aggregation functions ignore NULL values SELECT COUNT(*) AS total_customers, COUNT(primary_phone) AS customers_with_primary_phone, COUNT(DISTINCT primary_phone) AS unique_phone_numbers, COUNT(email_address) AS customers_with_email, COUNT(home_address) AS customers_with_home_address; -- Statistics with NULL handling SELECT 'Primary Phone' AS contact_type, COUNT(*) AS total_records, COUNT(primary_phone) AS non_null_count, COUNT(*) - COUNT(primary_phone) AS null_count, ROUND((COUNT(primary_phone) * 100.0) / COUNT(*), 2) AS completion_percentage UNION ALL SELECT 'Email Address' AS contact_type, COUNT(*) AS total_records, COUNT(email_address) AS non_null_count, COUNT(*) - COUNT(email_address) AS null_count, ROUND((COUNT(email_address) * 100.0) / COUNT(*), 2) AS completion_percentage UNION ALL SELECT 'Home Address' AS contact_type, COUNT(*) AS total_records, COUNT(home_address) AS non_null_count, COUNT(*) - COUNT(home_address) AS null_count, ROUND((COUNT(home_address) * 100.0) / COUNT(*), 2) AS completion_percentage FROM customer_contacts; -- Advanced aggregation with NULL handling SELECT CASE WHEN primary_phone IS NOT NULL AND email_address IS NOT NULL THEN 'Complete Contact Info' WHEN primary_phone IS NOT NULL OR email_address IS NOT NULL THEN 'Partial Contact Info' ELSE 'Missing Contact Info' END AS contact_completeness, COUNT(*) AS customer_count, ROUND((COUNT(*) * 100.0) / (SELECT COUNT(*) FROM customer_contacts), 2) AS percentage, -- Average note length (ignoring NULLs) ROUND(AVG(LENGTH(notes)), 2) AS avg_notes_length, -- Include NULL values in average calculation ROUND(AVG(COALESCE(LENGTH(notes), 0)), 2) AS avg_notes_length_including_nulls FROM customer_contacts GROUP BY contact_completeness ORDER BY customer_count DESC;

⚠️ Common Mistakes & Best Practices

Common NULL Handling Mistakes:

❌ Using = or != with NULL: WHERE column = NULL work aagadhu, IS NULL use pannunga
❌ Forgetting NULL in calculations: NULL + 5 = NULL, calculations-la NULL values handle pannunga
❌ String concatenation with NULL: CONCAT with NULL entire result NULL aagum
❌ NOT IN with NULL: Subquery results-la NULL irundha NOT IN unexpected results kudukum
❌ Assuming COUNT() counts NULLs: COUNT(column) NULL values ignore pannum

NULL Handling Best Practices:

✅ Always use IS NULL/IS NOT NULL: Never use = or != for NULL comparisons
✅ Provide meaningful defaults: COALESCE or IFNULL use panni user-friendly defaults kudunga
✅ Handle NULLs in joins: LEFT JOIN results-la NULL values expect pannunga
✅ Document NULL behavior: Application logic-la NULL handling strategy document pannunga
✅ Test edge cases: NULL values-oda application behavior test pannunga
✅ Use constraints wisely: Critical fields-ku NOT NULL constraint add pannunga

📚 Quick Reference

  • NULL Check: WHERE column IS NULL / IS NOT NULL
  • Replace NULL: COALESCE(col, 'default') or IFNULL(col, 'default')
  • Create NULL: NULLIF(col, 'empty') converts 'empty' to NULL
  • Count non-NULL: COUNT(column) ignores NULL values
  • Aggregation: SUM, AVG, MIN, MAX ignore NULL values
  • String concat: Use COALESCE before CONCAT to handle NULL
  • Calculations: Any math with NULL results in NULL
  • JOIN behavior: NULL values don't match in JOIN conditions
