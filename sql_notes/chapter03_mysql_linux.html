⚠️ Common Issues & Solutions

Authentication Issues:

Problem: Root login access denied
Solution:
sudo mysql ALTER USER 'root'@'localhost' IDENTIFIED WITH mysql_native_password BY 'password'; FLUSH PRIVILEGES;

Service Won't Start:

Check logs:
sudo journalctl -u mysql sudo tail -f /var/log/mysql/error.log

Port Already in Use:

Check what's using port 3306:
sudo netstat -tlnp | grep :3306 sudo lsof -i :3306
