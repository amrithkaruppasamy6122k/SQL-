📖 Definition

WHERE Clause: WHERE clause use panni specific conditions mention panni data filter pannalam. Simple-a sonna database-la irukura all records illa, nama venum-na records mattum retrieve pannalam. Idhu SELECT, UPDATE, DELETE commands-la romba important role play pannum.

📊 Comparison Operators

-- Equal to (=) SELECT * FROM employees WHERE department = 'IT'; -- Not equal to (!=) SELECT * FROM employees WHERE city != 'Chennai'; -- Greater than (>) SELECT * FROM employees WHERE salary > 45000; -- Less than (<) SELECT * FROM employees WHERE age < 29; -- Greater than or equal (>=) SELECT * FROM employees WHERE salary >= 46000; -- Less than or equal (<=) SELECT * FROM employees WHERE age <= 27;
Comparison Operators Explanation:
department = 'IT' - Department exactly 'IT' irukura records
city != 'Chennai' - Chennai illa-na other cities records
salary > 45000 - 45000-ku mela salary irukura employees
age < 29 - 29 years-ku kela age irukura employees
salary >= 46000 - 46000 or adhu mela salary
age <= 27 - 27 or adhu kela age

🔗 Logical Operators (AND, OR, NOT)

-- AND operator - both conditions must be true SELECT * FROM employees WHERE department = 'IT' AND salary > 45000; -- OR operator - either condition can be true SELECT * FROM employees WHERE city = 'Chennai' OR city = 'Mumbai'; -- NOT operator - opposite condition SELECT * FROM employees WHERE NOT department = 'HR'; -- Complex combinations SELECT * FROM employees WHERE (department = 'IT' OR department = 'Finance') AND salary > 45000; -- Multiple AND conditions SELECT * FROM employees WHERE age >= 28 AND city = 'Chennai' AND salary < 50000;
Logical Operators Explanation:
department = 'IT' AND salary > 45000 - IT department-la irundhu 45000-ku mela salary
city = 'Chennai' OR city = 'Mumbai' - Chennai or Mumbai-la irukuravanga
NOT department = 'HR' - HR department illa-na mathavanga
(department = 'IT' OR department = 'Finance') - Brackets use panni priority kudukom

🔍 Pattern Matching with LIKE

-- Names starting with 'R' SELECT * FROM employees WHERE name LIKE 'R%'; -- Names ending with 'a' SELECT * FROM employees WHERE name LIKE '%a'; -- Names containing 'ar' SELECT * FROM employees WHERE name LIKE '%ar%'; -- Names with exactly 3 characters in specific pattern SELECT * FROM employees WHERE name LIKE 'R_j%'; -- Case insensitive search SELECT * FROM employees WHERE name LIKE '%KUMAR%'; -- Multiple pattern conditions SELECT * FROM employees WHERE name LIKE 'P%' OR name LIKE 'M%';

LIKE Pattern Symbols:

  • % - Zero or more characters represent pannum
  • _ - Exactly one character represent pannum
LIKE Pattern Explanation:
'R%' - R-la start aagura ella names
'%a' - a-la end aagura ella names
'%ar%' - Enga venumanalum 'ar' irukura names
'R_j%' - R-la start, 3rd position-la j irukura names
'%KUMAR%' - Case sensitive illa, kumar word irukura names

📈 Range Operations (BETWEEN)

-- Salary range filter SELECT * FROM employees WHERE salary BETWEEN 42000 AND 46000; -- Age range filter SELECT * FROM employees WHERE age BETWEEN 26 AND 29; -- Date range filter SELECT * FROM employees WHERE hire_date BETWEEN '2022-01-01' AND '2022-12-31'; -- NOT BETWEEN - exclude range SELECT * FROM employees WHERE salary NOT BETWEEN 43000 AND 47000; -- Combining with other conditions SELECT * FROM employees WHERE salary BETWEEN 40000 AND 50000 AND department = 'IT';
BETWEEN Explanation:
BETWEEN 42000 AND 46000 - 42000 to 46000 range-la irukura salary (including boundaries)
BETWEEN '2022-01-01' AND '2022-12-31' - 2022 year-la join aana employees
NOT BETWEEN 43000 AND 47000 - Inda range-ku velila irukura salaries
BETWEEN is inclusive - Start and end values included aagum

📝 IN and NOT IN Operations

-- Multiple specific values SELECT * FROM employees WHERE city IN ('Chennai', 'Mumbai', 'Delhi'); -- Multiple departments SELECT * FROM employees WHERE department IN ('IT', 'Finance'); -- NOT IN - exclude specific values SELECT * FROM employees WHERE department NOT IN ('HR', 'Marketing'); -- Numbers with IN SELECT * FROM employees WHERE age IN (26, 28, 30); -- Combining IN with other conditions SELECT * FROM employees WHERE city IN ('Chennai', 'Bangalore') AND salary > 45000;
IN Operations Explanation:
IN ('Chennai', 'Mumbai', 'Delhi') - Inda cities-la yaaraachu irundha select aagum
department IN ('IT', 'Finance') - IT or Finance department employees
NOT IN ('HR', 'Marketing') - HR and Marketing illa-na mathavanga
IN vs OR: IN use panradhu short and clean

❓ NULL Value Handling

-- Add some NULL values for demonstration UPDATE employees SET city = NULL WHERE id = 5; -- Find NULL values SELECT * FROM employees WHERE city IS NULL; -- Find non-NULL values SELECT * FROM employees WHERE city IS NOT NULL; -- NULL with other conditions SELECT * FROM employees WHERE salary > 40000 AND city IS NOT NULL; -- Count NULL values SELECT COUNT(*) as null_cities FROM employees WHERE city IS NULL;
⚠️ NULL Handling Important Points:
• NULL values-ku = or != operators use panna koodadhu
• Always IS NULL or IS NOT NULL use pannunga
• NULL means 'unknown' or 'missing value'
• Mathematical operations with NULL = NULL
NULL Operations Explanation:
IS NULL - Column-la value illa-na (empty) select pannum
IS NOT NULL - Column-la value irukura records select pannum
city = NULL (Wrong!) - Idhu work aagadhu
city IS NULL (Correct!) - Idhu dhaan correct method

🔧 Complex WHERE Examples

-- Complex condition with multiple operators SELECT name, department, salary, age FROM employees WHERE (department = 'IT' AND salary >= 45000) OR (department = 'Finance' AND age > 28) OR (city IN ('Chennai', 'Mumbai') AND salary BETWEEN 40000 AND 47000); -- Date-based complex filtering SELECT * FROM employees WHERE hire_date >= '2022-01-01' AND department NOT IN ('HR') AND salary > 42000 AND name LIKE '%a%'; -- Salary analysis with multiple conditions SELECT name, salary, CASE WHEN salary >= 48000 THEN 'High' WHEN salary >= 45000 THEN 'Medium' ELSE 'Low' END as salary_grade FROM employees WHERE age BETWEEN 25 AND 30 AND city IS NOT NULL;
Complex WHERE Explanation:
Parentheses () - Condition priority set panna use panrom
Multiple OR conditions - Any one condition true-na enough
CASE statement - Conditional logic add pannalam
Combined conditions - Multiple operators mix panni use pannalam

📝 WHERE Clause Best Practices

Performance & Best Practices:

✅ Index Columns: WHERE clause-la use panra columns-ku index create pannunga
✅ Specific First: Most selective condition-a first-a venga
✅ Avoid Functions: WHERE column functions apply panna koodadhu
✅ Use LIMIT: Large result sets-ku LIMIT use pannunga
✅ Test Conditions: Complex conditions-a small data-la test pannunga

Common Mistakes to Avoid:

❌ NULL Comparison: WHERE column = NULL (wrong!)
❌ String Quotes: WHERE name = Raj (quotes missing!)
❌ Case Sensitivity: MySQL default-a case insensitive, but data check pannunga
❌ Date Format: Proper date format use pannunga 'YYYY-MM-DD'

📚 Quick Reference

  • Comparison: =, !=, >, <, >=, <=
  • Logical: AND, OR, NOT
  • Pattern: LIKE '%pattern%', LIKE 'pattern_'
  • Range: BETWEEN min AND max
  • List: IN (value1, value2, value3)
  • NULL: IS NULL, IS NOT NULL
  • Grouping: Use parentheses () for complex conditions
