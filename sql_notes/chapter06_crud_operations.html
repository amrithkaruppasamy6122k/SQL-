Chapter 6: CRUD Operations - Complete Guide

📖 Definition

CRUD Operations: CRUD ennanagra Create, Read, Update, Delete. Database-la panna koodiya basic 4 operations idhu dhaan. Any application-la data management-ku inda 4 operations mandatory. Facebook-la post create panradhu, Instagram-la photos paappradhu, WhatsApp-la message edit panradhu - ellame CRUD operations dhaan.

🎯 CRUD Overview

🆕 CREATE

New Data Add panradhu

SQL Command: INSERT

Examples: New user register, New product add

👁️ READ

Data Retrieve panradhu

SQL Command: SELECT

Examples: User profile view, Product list show

✏️ UPDATE

Existing Data Modify panradhu

SQL Command: UPDATE

Examples: Profile edit, Price change

🗑️ DELETE

Data Remove panradhu

SQL Command: DELETE

Examples: Account delete, Post remove

💡 Sample Database Setup

-- Sample database and table create panrom CREATE DATABASE IF NOT EXISTS company_db; USE company_db; CREATE TABLE employees ( id INT PRIMARY KEY AUTO_INCREMENT, name VARCHAR(100) NOT NULL, department VARCHAR(50), salary DECIMAL(10,2), hire_date DATE, email VARCHAR(100) UNIQUE );
Table Structure Explanation:
id INT PRIMARY KEY AUTO_INCREMENT - Unique ID, automatic-a increment aagum
name VARCHAR(100) NOT NULL - Employee name, mandatory field
department VARCHAR(50) - Department name, optional
salary DECIMAL(10,2) - Salary amount with 2 decimal places
hire_date DATE - Joining date
email VARCHAR(100) UNIQUE - Email address, duplicate illa

🆕 CREATE Operation (INSERT)

-- Single record insert panradhu INSERT INTO employees (name, department, salary, hire_date, email) VALUES ('Raj Kumar', 'IT', 45000.00, '2024-01-15', 'raj.kumar@company.com'); -- Multiple records insert panradhu INSERT INTO employees (name, department, salary, hire_date, email) VALUES ('Priya Sharma', 'HR', 42000.00, '2024-02-01', 'priya.sharma@company.com'), ('Karthik Reddy', 'Finance', 48000.00, '2024-02-15', 'karthik.reddy@company.com'), ('Meena Patel', 'IT', 46000.00, '2024-03-01', 'meena.patel@company.com'); -- Partial data insert (some columns only) INSERT INTO employees (name, department) VALUES ('Temporary Employee', 'Operations');
INSERT Command Explanation:
INSERT INTO employees - Employees table-la data add pannurom
(name, department, salary...) - Enna columns-ku data kudukkurom-nu specify panrom
VALUES ('Raj Kumar', 'IT'...) - Actual data values kudukurom
Multiple VALUES - Oru query-la multiple records add pannalam
Partial INSERT - Required columns mattum kudukkalam

👁️ READ Operation (SELECT)

-- All records select panradhu SELECT * FROM employees; -- Specific columns select panradhu SELECT name, department, salary FROM employees; -- Condition-oda records select panradhu SELECT * FROM employees WHERE department = 'IT'; -- Salary range filter panradhu SELECT name, salary FROM employees WHERE salary BETWEEN 40000 AND 50000; -- Sorting with ORDER BY SELECT * FROM employees ORDER BY salary DESC; -- Limited results SELECT * FROM employees ORDER BY hire_date DESC LIMIT 3;
SELECT Command Explanation:
SELECT * - Ella columns-um select panrom
SELECT name, department - Specific columns mattum select panrom
WHERE department = 'IT' - IT department employees mattum filter panrom
BETWEEN 40000 AND 50000 - Salary range-oda filter panrom
ORDER BY salary DESC - Salary high-to-low sorting panrom
LIMIT 3 - First 3 records mattum display panrom

Sample Results:

✏️ UPDATE Operation

-- Single record update panradhu UPDATE employees SET salary = 47000.00 WHERE id = 1; -- Multiple columns update panradhu UPDATE employees SET salary = 50000.00, department = 'Senior IT' WHERE name = 'Raj Kumar'; -- Conditional update panradhu UPDATE employees SET salary = salary * 1.10 WHERE department = 'IT'; -- All records update panradhu (dangerous!) UPDATE employees SET hire_date = CURDATE() WHERE hire_date IS NULL;
UPDATE Command Explanation:
UPDATE employees - Employees table-la update pannurom
SET salary = 47000.00 - Salary column-ku new value set panrom
WHERE id = 1 - ID 1 irukura record mattum update pannurom
salary = salary * 1.10 - Current salary-ku 10% increment panrom
WHERE hire_date IS NULL - Hire date illa records-ku current date set panrom
⚠️ UPDATE Warning: WHERE clause illa-na ella records-um update aayidum! Always WHERE condition use pannunga.

🗑️ DELETE Operation

-- Single record delete panradhu DELETE FROM employees WHERE id = 5; -- Condition-oda delete panradhu DELETE FROM employees WHERE department = 'Operations' AND salary IS NULL; -- Multiple conditions-oda delete DELETE FROM employees WHERE hire_date < '2024-01-01' OR salary < 30000; -- All records delete panradhu (very dangerous!) -- DELETE FROM employees; -- Table structure-oda delete panradhu -- TRUNCATE TABLE employees;
DELETE Command Explanation:
DELETE FROM employees - Employees table-la irundhu delete panrom
WHERE id = 5 - ID 5 irukura record mattum delete panrom
AND salary IS NULL - Multiple conditions check panrom
OR salary < 30000 - Either condition true-na delete aagum
TRUNCATE - Ella data-yum fast-a delete pannum, structure remain aagum
⚠️ DELETE Warning: WHERE clause illa-na ella records-um delete aayidum! Always backup eduthu, WHERE condition confirm pannunga.

📝 CRUD Best Practices

  • Data Validation: INSERT/UPDATE-ku munadi data validate pannunga
  • Use Transactions: Critical operations-ku transaction use pannunga
  • Backup First: UPDATE/DELETE-ku munadi backup edunga
  • Test Queries: Production-la run panna munadi test pannunga
  • Use WHERE: UPDATE/DELETE-la always WHERE clause use pannunga
  • Soft Delete: Important data-ku actual delete panna koodadhu
